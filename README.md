**Study Buddy — LangChain Retrieval Project**

- **Description**: Study Buddy is a small LangChain-based retrieval application that ingests documents, builds a FAISS index, and runs question-answering/chain logic over the indexed content.

**Prerequisites**
- Python 3.10+ (virtualenv recommended)
- [FAISS index file is stored under `faiss_index/index.faiss`]

**Quick Setup**
- Create and activate a virtual environment, then install dependencies:

```bash
python -m venv venv
# Windows PowerShell
venv\Scripts\Activate.ps1
# or Windows cmd
venv\Scripts\activate.bat
pip install -r requirements.txt
```

**Project Files**
- [ingest.py](ingest.py): Ingests source data from `data/` and builds/updates the FAISS index.
- [chain.py](chain.py): Defines the chain/pipeline used to perform question-answering over the retriever.
- [main.py](main.py): Example runner that ties together ingestion, retrieval, or interactive querying (project-specific entrypoint).
- [retriever.py](retriever.py): Implements retrieval logic and FAISS index access.
- [memory.py](memory.py): Implements session or conversational memory helpers used by chains.
- `requirements.txt`: Python dependencies.
- `data/`: Directory for source documents (PDFs, text, etc.).
- `faiss_index/index.faiss`: Binary FAISS index file (generated by `ingest.py`).

**Common Commands**
- Ingest source documents and (re)build the FAISS index:

```bash
python ingest.py
```

- Run the main application / demo (adjust depending on how `main.py` is implemented):

```bash
python main.py
```

- Run the chain or a script that executes query logic directly:

```bash
python chain.py
```

**How it works (high level)**
- `ingest.py` reads files from `data/`, converts them to embeddings, and stores them in a FAISS index at `faiss_index/index.faiss`.
- `retriever.py` loads the FAISS index and provides nearest-neighbor retrieval for query embeddings.
- `chain.py` wires retriever results into a prompt/chain that produces answers.
- `memory.py` optionally keeps conversation context when running multi-turn interactions.

**Rebuilding the Index**
1. Clear or remove `faiss_index/index.faiss` (if you want a fresh index).
2. Update or add files under `data/`.
3. Run:

```bash
python ingest.py
```

**Environment / API keys**

```bash
# example (PowerShell)
$env:OPENAI_API_KEY = "your_api_key_here"
```

**Troubleshooting**
- Missing dependencies: ensure `pip install -r requirements.txt` completes without errors.
- Index load errors: verify `faiss_index/index.faiss` exists and matches the expected embeddings dimension.
- Model/API errors: check that required API keys are set as env vars and that network access is available.

**Development Tips**
- Keep source documents small or split large ones to avoid oversized embeddings per document.
- Version your index: keep backups of `faiss_index/` if rebuilding frequently.
